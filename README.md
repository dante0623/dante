# Mellojoy 予約アシスタント（試作版）

iPhoneで使いやすい、原宿・渋谷の入店予約準備を助ける静的Webアプリです。予約枠の取得、選択、送信は一切行いません。公式ページをユーザーが開いて手動で予約するための、希望日時・受付開始時刻・リマインダー・記録をまとめたツールです。

## iPhoneで使う（おすすめ）

1. このアプリをHTTPS対応の静的ホスティングに配置し、iPhoneのSafariでURLを開きます。
2. Safariの共有ボタンから「ホーム画面に追加」を選びます。
3. 追加された「Mellojoy予約」を開き、希望日時を保存します。
4. 受付開始時刻になったら、アプリの「公式予約ページを開く」を押し、**同じiPhoneで**予約とQRコード表示を行います。

予約内容そのものは公式予約サイトが管理します。このアプリは予約を代行・同期せず、希望設定と手動確認の記録だけを、このiPhone内に保存します。

## ローカルで試す

追加のインストールは不要です。`index.html` をブラウザで開いてください。ローカルHTTPサーバーを使う場合は、プロジェクトのフォルダで次を実行します。

```sh
python3 -m http.server 8000
```

その後、`http://localhost:8000` を開きます。ホーム画面追加やオフライン画面には、HTTPSでの公開が必要です。

## できること

- 原宿・渋谷の切り替え、希望日・希望時刻・会場優先順位の端末内保存
- 原宿（希望日の6日前 13:00）と渋谷（前日 13:00）の受付開始予定カウントダウン
- ブラウザ通知の許可と、カレンダー用 `.ics` リマインダーのダウンロード
- 利用者が押したときだけ公式予約ページを開く、手動確認の時刻記録
- 予約完了後の手動ステータス記録

## 制限と安全設計

- バックグラウンドでの継続監視、スクレイピング、予約枠の自動確認はしません。
- 予約枠の自動選択・送信、待機列やCAPTCHAの回避はしません。
- ブラウザ通知は、このページが開かれている間に限られます。確実なリマインダーにはカレンダー追加を使ってください。
- 保存内容はこのブラウザの `localStorage` のみです。予約番号や個人情報は保存しません。
